# SoilMind chatbot training dataset (Member 4)

> **Read this first. No question in this dataset was written or checked by a person.** Every row is either
> generated by code (templates, paraphrases), drafted by the AI coding assistant (Claude Code), or
> machine-translated by NLLB-200. All rows have `checked_by_human = no`. The `source` and `author` columns say
> which. The trained intent classifier and retriever were trained on this data as it is. The team reviews
> only the end-to-end evaluation set (`backend/member4-chatbot/eval/qa_testset.xlsx`), not this dataset.

Built by `python -m member4_chatbot.dataset.build` (seed 20261018). All numbers below are written by that
command from the CSV files, so they always match them.

- `qa_pairs.csv`: id, question, answer, lang, answer_lang, intent, passage_id, also_correct, split, source,

- `lang`: `en` English, `si` Sinhala script, `si_latn` Sinhala typed in Latin letters ("Singlish").

### 1. Template questions from structured data (`auto_template`)
`member4_chatbot/dataset/templates.py` reads numbers from the downloaded documents and writes questions and
answers in English and, with separate Sinhala templates, in Sinhala. Every number in these answers is exact:
- RRDI fertilizer recommendation tables, four zone / water pages. The English and Sinhala page of each zone are
  parsed separately and the build stops if they disagree (they agree). Per-acre values are kg/ha / 2.471.
- RRDI "fertilizer by soil test report" table (TSP by soil P, MOP by soil K).
- RRDI variety sheets: maturity, average yield, release year, recommended region, resistance ratings.
- NAICC paddy crop calendar, Dry and Intermediate Zone (irrigated): urea kg/ac per split, pests by month, seed
  paddy per acre. **The calendar is a JPG poster; its text was transcribed by hand** (see
  `data/docs/manual_text/README.md`), so these rows depend on that transcription.

Fertilizer split and variety resistance questions are capped and sampled with the seed so they do not swamp the

### 2. AI-drafted questions (`ai_drafted`)
These were drafted by the AI coding assistant, not by team members.
- `sources/ai_drafted_en.yaml`: English questions, each tied to a passage by document + anchor phrase, with an
  answer of 1-3 short sentences that only restates that passage.
- `sources/ai_drafted_si.yaml`: questions drafted directly in Sinhala from the Sinhala RRDI pages
  (fertilizer tables, blast, weeds, nurseries, land preparation, transplanting, seeding, varieties).
- `sources/ai_drafted_intents.yaml`: intent examples with no passage: live-field questions (`my_field_status`),
  greetings, Singlish, and deficiency / liming questions whose leaflets still need OCR.
- `sources/ai_drafted_refusals.yaml`: refusals in 9 categories, including "near misses" (other crops, livestock,
  tractor prices, loans) so the model cannot learn "any farm word = in scope".

**Authorship, plainly.** 743
rows were drafted by the AI coding assistant (Claude Code) while building the project, not by the team, and none
has been checked by a person. Change of plan (Phase 6): the team does **not** review this training data; it
reviews the 60-question evaluation set in `eval/qa_testset.xlsx` instead. The models are trained on this
unchecked data, so their scores here are scores on AI-drafted / machine-translated questions.

### 3. Paraphrases (`auto_paraphrase`)
`member4_chatbot/dataset/paraphrase.py`: one rule-based paraphrase per AI-drafted English question (phrase
swaps such as "how much" -> "what amount of", "paddy" <-> "rice", farmer-style framing, dropped capitals). No
model is used. Numbers, variety names, nutrients and units are never changed.

### 4. Machine translation to Sinhala (`machine_translated`)
Every AI-drafted English question (and the answer, for passage questions) was translated with
**facebook/nllb-200-distilled-600M** run locally on CPU (`member4_chatbot/dataset/translate.py`, beam 4).
Translations are cached in `sources/nllb_translations.csv`. They are first drafts: NLLB sometimes translates
agricultural terms literally (e.g. product names such as TSP / MOP) or picks formal words a farmer would not use.
**None has been checked by a Sinhala speaker yet** (`checked = no`). Mistakes already seen in a spot check:
- "weeds" → කෘමීන් ("insects")
- "herbicide" → විෂබීජ නාශක ("disinfectant")
- "irrigated" → වැසි කරන ලද ("rained")
- "rice" → රයිස් (transliterated) instead of වී / සහල්
- "kresek" was not understood

So some Sinhala rows have the wrong meaning, not just awkward wording. NLLB also drops the zero-width joiner
inside conjunct letters (ප් රමාණය instead of ප්‍රමාණය). `translate.repair_zwj` re-joins these: it joins only when the
left part is a lone consonant or not a word in our Sinhala corpus. That fixed 735 of 784 cases; the cache keeps the
raw output. To fix a row, edit `translation`, set
`checked` to `yes` and rebuild; checked rows are never overwritten and become `checked_by_human = yes`.
NLLB-200's weights are licensed CC-BY-NC 4.0 (non-commercial), which fits a university project.

### 5. Open datasets
No outside dataset was added (the brief makes this optional). Agricultural QA sets on Hugging Face are English,
mostly Indian or US crops, so they would add noise to a Sri Lankan paddy bot; this can be revisited.

## Splits
- train / val / test = 70 / 15 / 15, assigned per **group**, seed 20261018.
- A group is one passage plus its other-language twin (linked through `also_correct`), so **no passage appears in
  two splits** (tested in `tests/test_m4_dataset.py`). Questions without a passage are grouped with their own
  paraphrase and translation, so a question and its translation are never split apart.
- Within each intent the groups are assigned greedily to the split furthest below its 70 / 15 / 15 share.

## Known limitations
1. Most deficiency and many water / weed leaflets (NAICC, RRDI Sinhala) are scanned images; Tesseract was not
   available on the build machine, so they are not in the knowledge base yet and `deficiency_symptom` /
   `liming_ph` have few passage-based questions. Install Tesseract with Sinhala data and re-run
   `python -m member4_chatbot.ingest.run` and this build.
2. No row is human-written or human-checked; machine-translated Sinhala includes wrong meanings (see above).
3. Template questions are regular in form; the test set also contains hand-written and translated questions so
   the models are not judged on templates only.
